Guia Comparativo de Semântica: C e Python

Tabela-mestra de diferenças de execução, modelos de memória, coerção de tipos e armadilhas da banca do IFCE.

Atenção às nuances cobradas pela banca: A banca examinadora do PPGCC/IFCE não cobra programação genérica; ela cobra semântica estrita da linguagem. Questões típicas exploram divisão de inteiros em C, coerções de tipos primitivos, rastreamento de laços com variáveis auxiliares e profundidade de pilhas em recursão.

1. Tabela Comparativa de Operações e Semântica

Aspecto Linguagem C (ANSI C99) Linguagem Python (Python 3.x)
Tipagem Estática, fraca (permite coerções implícitas perigosas) Dinâmica, forte (rejeita somar int com string)
Operador / Divisão inteira se ambos forem int (trunca casas decimais: 10/3 = 3) Sempre divisão em ponto flutuante real (10/3 = 3.3333333333333335)
Divisão Inteira a / b (quando $a, b \in \mathbb{Z}$) Operador explícito a // b (divisão pelo piso / floor)
Passagem de Parâmetros Exclusivamente por valor (referência é emulada passando ponteiros de memória) Passagem por atribuição de objeto (*pass-by-object-reference*)
Strings Vetor contíguo de char terminado pelo byte nulo '\0' Objeto atômico imutável de primeira classe
Curto-Circuito && e || avaliam apenas o estritamente necessário and e or retornam o operando decisivo, não só bool

2. Aritmética de Ponteiros em C

Fórmula Fundamental do Offset de Memória
$$\text{Endereço}(v[i]) = \text{EndereçoBase}(v) + i \times \operatorname{sizeof}(\text{Tipo})$$
🗣️ Como se lê: "O endereço do elemento $i$ do vetor é igual ao endereço base mais o deslocamento de $i$ vezes o tamanho do tipo de dado em bytes"
Consequência imediata: A expressão v[i] é uma forma sintática reduzida para *(v + i).
Curiosidade cobrada em questões formais: Em C, como a adição comutativa se aplica, i[v] é sintaticamente idêntico a v[i]!

3. O Mecanismo da Pilha de Chamadas (*Call Stack*)

Toda chamada de função empilha um Registro de Ativação (*Stack Frame*) na memória com:

  • Endereço de retorno na instrução que chamou;
  • Parâmetros recebidos pela função;
  • Variáveis locais declaradas na função.

Em recursão, se a função fizer $k$ chamadas aninhadas antes de atingir o caso base, a profundidade da pilha será de $O(k)$ registros. Se a pilha estourar o limite de memória do sistema operacional, ocorre o clássico Stack Overflow.
